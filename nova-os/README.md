# Nova OS

AI-first financial operating system prototype.

## Demo capabilities

- Executive financial overview
- Cash-flow scenario model
- Payment approval workflow
- Global payroll review workflow
- Treasury scenario planning
- Portfolio dashboard
- Invoice monitoring
- AI CFO demo copilot
- Analytics and settings
- Responsive dark/light UI

All data is simulated locally. No banking credentials, custody, or real-money transfers are enabled.

## Run locally

Open `index.html` in a browser or serve the folder with any static HTTP server.

## Production roadmap

1. Authentication and RBAC
2. PostgreSQL financial ledger
3. Provider integrations for read-only financial data
4. Payment orchestration with regulated partners
5. Audit logs and approvals
6. AI tool-use with strict authorization boundaries
7. Observability and security controls
8. Jurisdiction-specific compliance review
