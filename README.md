# NovaX + ResumeForge

This repository contains two independent open-source web products:

## NovaX
A visually rich crypto market-data and paper-trading sandbox. It uses public market data and simulates orders locally; it does not custody funds or execute real cryptocurrency trades.

**Vercel root:** repository root (`.`)

## ResumeForge
A free, privacy-first resume builder with regional guidance, multiple templates, live preview and browser-based PDF export.

**Vercel root:** `resumeforge`
