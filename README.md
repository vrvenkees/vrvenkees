# ResumeForge

A free, open-source, privacy-first resume builder. Build a polished ATS-friendly resume in your browser and print/download it as PDF.

## Features

- Live resume preview
- Classic, Modern and Minimal templates
- Experience, education, skills, certifications, projects and languages
- Local browser storage — no account or backend required
- Responsive design
- Print / PDF export
- Open source

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.
